# サワードウ水分量比率プランナー

小麦粉の種類・スターター活性度・目標食感・発酵温度を入力すると、最適な加水率・水量・塩量・スターター量・オートリーズ時間・発酵時間を自動計算するプランナーアプリです。開始時刻を設定すると全工程のタイムラインスケジュールを生成し、レシピはlocalStorageに最大10件保存・呼び出しができます。

## 機能
- 小麦粉重量・種類・スターター活性度・目標食感・発酵温度の入力
- 加水率・水/塩/スターター重量の自動計算
- バルク発酵時間・最終発酵時間の温度別推定
- 開始時刻から全工程の時刻付きタイムライン生成
- レシピの名前付き保存・読込・削除（localStorage）
